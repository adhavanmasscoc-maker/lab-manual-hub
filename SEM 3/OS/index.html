System Calls: Fork, Exit, Getpid, Wait, Close

Aim

To write, execute, and demonstrate process management system calls including fork(), getpid(), getppid(), wait(), exit(), and file management system calls open() and close() in C under UNIX/Linux operating systems.

Algorithm
  1. Start the program.
  2. Declare a process identifier variable pid_t pid.
  3. Invoke the fork() system call to spawn a child process:
    • If pid < 0: Process creation failed; print error message and exit with status 1.
    • If pid == 0: Execution is currently inside the Child Process. Retrieve the Child Process ID using getpid() and Parent Process ID using getppid(). Terminate child using exit(0).
    • If pid > 0: Execution is inside the Parent Process. Call wait(NULL) to suspend parent execution until the child terminates. Retrieve parent PID with getpid().
  4. Demonstrate open() and close() file descriptor system calls by opening a file and closing its descriptor using close(fd).
  5. Stop the program.
Program 1: fork(), getpid(), getppid(), wait(), exit()
process.c
#include <stdio.h>
#include <stdlib.h>
#include <unistd.h>
#include <sys/wait.h>

int main() {
    pid_t pid;
    pid = fork();
    
    if(pid < 0) {
        printf("Fork Failed!
");
        exit(1);
    }
    else if(pid == 0) {
        printf("
--- CHILD PROCESS ---
");
        printf("Child Process ID (PID)   : %d
", getpid());
        printf("Parent Process ID (PPID) : %d
", getppid());
        exit(0);
    }
    else {
        wait(NULL);
        printf("
--- PARENT PROCESS (Resumed after Child Exit) ---
");
        printf("Parent Process ID (PID)  : %d
", getpid());
        printf("Grandparent PID (Bash)   : %d
", getppid());
    }
    return 0;
}

CPU Scheduling Algorithms (FCFS, SJF, Priority, Round Robin)

Aim

To write C programs to simulate CPU Scheduling Algorithms namely First Come First Serve (FCFS), Shortest Job First (SJF - Non-Preemptive), Priority Scheduling (Non-Preemptive), and Round Robin (RR), and compute Waiting Time, Turnaround Time, Average Waiting Time, and Average Turnaround Time for each algorithm.

1. First Come First Serve (FCFS) Scheduling

Algorithm:

  1. Start the program.
  2. Input the number of processes n and the Burst Time (BT) for each process.
  3. Waiting time for the first process is zero: wt[0] = 0.
  4. For all subsequent processes i = 1 to n-1, calculate waiting time: wt[i] = wt[i-1] + bt[i-1].
  5. For every process i = 0 to n-1, calculate turnaround time: tat[i] = wt[i] + bt[i].
  6. Calculate Average Waiting Time = (Sum of all wt[i]) / n and Average Turnaround Time = (Sum of all tat[i]) / n.
  7. Display the scheduling result table.
fcfs.c
#include <stdio.h>

int main() {
    int n, i, bt[20], wt[20], tat[20];
    float avg_wt = 0, avg_tat = 0;
    
    printf("Enter Number of Processes: "); 
    scanf("%d", &n);
    
    for(i = 0; i < n; i++) {
        printf("Enter Burst Time for P%d: ", i + 1);
        scanf("%d", &bt[i]);
    }
    
    wt[0] = 0;
    for(i = 1; i < n; i++) {
        wt[i] = wt[i - 1] + bt[i - 1];
    }
    
    for(i = 0; i < n; i++) {
        tat[i] = wt[i] + bt[i];
        avg_wt += wt[i]; 
        avg_tat += tat[i];
    }
    
    printf("
Process	Burst Time	Waiting Time	Turnaround Time
");
    for(i = 0; i < n; i++) {
        printf("P%d	%d		%d		%d
", i + 1, bt[i], wt[i], tat[i]);
    }
    
    printf("
Average Waiting Time    = %.2f", avg_wt / n);
    printf("
Average Turnaround Time = %.2f
", avg_tat / n);
    return 0;
}

Algorithm:

  1. Start the program.
  2. Input number of processes n, process IDs p[], and burst times bt[].
  3. Sort the processes in ascending order of their burst times using bubble sort.
  4. Calculate wt[0] = 0, and for each subsequent process, wt[i] = wt[i-1] + bt[i-1].
  5. Compute turnaround times: tat[i] = wt[i] + bt[i].
  6. Calculate averages and display the scheduling table.

4. Round Robin (RR) Scheduling

Algorithm:

  1. Start the program.
  2. Input number of processes n, burst times bt[], and time quantum tq.
  3. Maintain a copy of remaining burst times: rem_bt[i] = bt[i]. Initialize current time time = 0.
  4. Loop continuously across processes:
    • If rem_bt[i] > tq: increment time += tq and decrement rem_bt[i] -= tq.
    • Else if rem_bt[i] > 0: increment time += rem_bt[i], calculate waiting time wt[i] = time - bt[i], and set rem_bt[i] = 0.
  5. Repeat step 4 until all processes have rem_bt[i] == 0.
  6. Calculate turnaround times: tat[i] = bt[i] + wt[i].
  7. Compute Average WT and Average TAT and print the results.
round_robin.c
#include <stdio.h>

int main() {
    int n, tq, i, bt[20], rem_bt[20], wt[20] = {0}, tat[20], time = 0, done;
    float avg_wt = 0, avg_tat = 0;
    
    printf("Enter Number of Processes: "); 
    scanf("%d", &n);
    
    for(i = 0; i < n; i++) {
        printf("Enter Burst Time for P%d: ", i + 1);
        scanf("%d", &bt[i]);
        rem_bt[i] = bt[i];
    }
    
    printf("Enter Time Quantum: "); 
    scanf("%d", &tq);
    
    do {
        done = 1;
        for(i = 0; i < n; i++) {
            if(rem_bt[i] > 0) {
                done = 0;
                if(rem_bt[i] > tq) {
                    time += tq;
                    rem_bt[i] -= tq;
                } else {
                    time += rem_bt[i];
                    wt[i] = time - bt[i];
                    rem_bt[i] = 0;
                }
            }
        }
    } while(!done);

    for(i = 0; i < n; i++) {
        tat[i] = bt[i] + wt[i];
        avg_wt += wt[i]; 
        avg_tat += tat[i];
    }

    printf("
Process	Burst Time	Waiting Time	Turnaround Time
");
    for(i = 0; i < n; i++) {
        printf("P%d	%d		%d		%d
", i + 1, bt[i], wt[i], tat[i]);
    }
    
    printf("
Average Waiting Time    = %.2f", avg_wt / n);
    printf("
Average Turnaround Time = %.2f
", avg_tat / n);
    return 0;
}

Inter Process Communication (IPC) using Pipe

Aim

To implement unidirectional Inter Process Communication (IPC) between a parent process and a child process using the pipe() system call in C under UNIX/Linux.

Algorithm
  1. Start the program.
  2. Declare an integer array fd[2] to hold read and write file descriptors.
  3. Invoke pipe(fd) system call to create a unidirectional data channel:
    • fd[0] represents the Read End of the pipe.
    • fd[1] represents the Write End of the pipe.
  4. Fork the process using pid = fork().
  5. If pid == 0 (Child Process):
    • Close the unused read descriptor: close(fd[0]).
    • Write the message string to fd[1] using write().
    • Close the write descriptor: close(fd[1]) and exit.
  6. If pid > 0 (Parent Process):
    • Wait for child using wait(NULL).
    • Close the unused write descriptor: close(fd[1]).
    • Read the message from fd[0] into a buffer using read().
    • Display the received string on the terminal and close fd[0].
  7. Stop the program.
C Program
ipc_pipe.c
#include <stdio.h>
#include <stdlib.h>
#include <unistd.h>
#include <string.h>
#include <sys/wait.h>

int main() {
    int fd[2];
    pid_t pid;
    char message[] = "Hello from Child Process via UNIX Pipe!";
    char buffer[100];
    
    if(pipe(fd) == -1) {
        printf("Pipe Creation Failed!
");
        return 1;
    }
    
    pid = fork();
    
    if(pid < 0) {
        printf("Fork Failed!
");
        return 1;
    }
    else if(pid == 0) {
        // Child Process writes to pipe
        close(fd[0]);
        write(fd[1], message, strlen(message) + 1);
        printf("Child: Message sent to pipe successfully.
");
        close(fd[1]);
        exit(0);
    } 
    else {
        // Parent Process reads from pipe
        wait(NULL);
        close(fd[1]);
        read(fd[0], buffer, sizeof(buffer));
        printf("Parent: Received message from child:
"%s"
", buffer);
        close(fd[0]);
    }
    return 0;
}

Semaphore Implementation (Mutual Exclusion)

Aim

To implement Mutual Exclusion for the Critical Section problem using POSIX Semaphores in C, ensuring that only one process can enter the critical section at any given time.

Algorithm
  1. Start the program.
  2. Allocate shared memory for a POSIX semaphore sem_t *sem using mmap() with MAP_SHARED flag.
  3. Initialize the binary semaphore with initial value 1: sem_init(sem, 1, 1).
  4. Fork the process into parent and child concurrent execution paths.
  5. Before accessing shared resources (Critical Section), invoke sem_wait(sem) (P operation). If semaphore value > 0, it decrements and proceeds; otherwise, the process blocks.
  6. Execute critical section operations (e.g., printing and updating shared state).
  7. Upon completing critical operations, invoke sem_post(sem) (V operation) to increment semaphore value and awaken blocked processes.
  8. Wait for child termination, destroy semaphore using sem_destroy(), and release memory.
  9. Stop the program.
C Program
semaphore.c
#include <stdio.h>
#include <stdlib.h>

Disk Scheduling Algorithms (FCFS, SSTF, SCAN, C-SCAN)

Aim

To write C programs to simulate and implement various Disk Scheduling Algorithms namely First Come First Serve (FCFS), Shortest Seek Time First (SSTF), SCAN (Elevator Algorithm), and Circular SCAN (C-SCAN), and calculate the total head movement (seek time) and average seek time for a given disk request queue.

1. First Come First Serve (FCFS) Disk Scheduling

Algorithm:

  1. Start the program.
  2. Input the number of I/O requests n in the disk queue.
  3. Input the track numbers of the request queue into an array req[].
  4. Input the initial read/write head position head.
  5. Service each track request strictly in the order in which they arrive in the queue.
  6. For each request req[i], calculate the absolute seek distance: diff = abs(req[i] - head).
  7. Add diff to the cumulative seek time: seek += diff.
  8. Update the current head position: head = req[i].
  9. Repeat steps 6 to 8 until all requests in the queue are serviced.
  10. Display the head movement order, Total Head Movement, and Average Seek Time.
  11. Stop the program.

#include <stdio.h>
#include <stdlib.h>

    printf("--- FCFS DISK SCHEDULING ---\n");
    printf("Enter Number of Requests: ");
    scanf("%d", &n);
    
    printf("Enter Request Queue:\n");
    for(i = 0; i < n; i++) {
        scanf("%d", &req[i]);
    }
    
    printf("Enter Initial Head Position: ");
    scanf("%d", &head);

    printf("\nHead Movement Traversal:\n%d", head);

        seek += diff;
        head = req[i];
        printf(" -> %d", head);
    }
    
    printf("\n\nTotal Head Movement (Seek Time) = %d Cylinders", seek);
    printf("\nAverage Seek Time = %.2f Cylinders\n", (float)seek / n);
    
    return 0;
}

2. Shortest Seek Time First (SSTF) Disk Scheduling

Algorithm:

  1. Start the program.
  2. Input the number of requests n, the request array req[], and initial head position head.
  3. Initialize an array visited[] of size n with all zeros to track serviced requests.
  4. Initialize count = 0 and seek = 0.
  5. While count < n:
    • Set min = 99999 and index = -1.
    • For each request i = 0 to n-1: if !visited[i], compute distance = abs(req[i] - head).
    • If distance < min, update min = distance and index = i.
  6. Mark request index as visited: visited[index] = 1.
  7. Add min to seek and update head: head = req[index].
  8. Increment count by 1.
  9. Print the total seek time and average seek time.
  10. Stop the program.
sstf_disk.c
#include <stdio.h>
#include <stdlib.h>

int main() {
    int req[50], visited[50] = {0}, n, head, i, count = 0, seek = 0, index, min, distance;
    
    printf("--- SSTF DISK SCHEDULING ---\n");
    printf("Enter Number of Requests: ");
    scanf("%d", &n);
    
    printf("Enter Request Queue:\n");
    for(i = 0; i < n; i++) {
        scanf("%d", &req[i]);
    }
    
    printf("Enter Initial Head Position: ");
    scanf("%d", &head);

    printf("\nHead Movement Traversal:\n%d", head);
    while(count < n) {
        min = 99999;
        for(i = 0; i < n; i++) {
            if(!visited[i]) {
                distance = abs(req[i] - head);
                if(distance < min) {
                    min = distance;
                    index = i;
                }
            }
        }
        visited[index] = 1;
        seek += min;
        head = req[index];
        printf(" -> %d", head);
        count++;
    }
    
    printf("\n\nTotal Head Movement (Seek Time) = %d Cylinders", seek);
    printf("\nAverage Seek Time = %.2f Cylinders\n", (float)seek / n);
    
    return 0;
}

3. SCAN (Elevator) Disk Scheduling

Algorithm:

  1. Start the program.
  2. Input disk capacity disk_size (e.g. 200 tracks, numbered 0 to 199), request count n, request array req[], and initial head position head.
  3. Sort the request array req[] in ascending numerical order.
  4. Find the partition index pos where requests become greater than the current head position.
  5. Move the disk arm in the high direction (from pos to n-1), adding the seek distance to each track.
  6. Move the head to the maximum disk boundary disk_size - 1 (track 199).
  7. Reverse direction and service the remaining requests downwards from pos - 1 down to 0.
  8. Accumulate all absolute differences into seek.
  9. Print the head movement sequence, Total Head Movement, and Average Seek Time.
  10. Stop the program.
scan_disk.c
#include <stdio.h>
#include <stdlib.h>

int main() {
    int req[50], n, head, disk_size, i, j, temp, seek = 0, pos;
    
    printf("--- SCAN (ELEVATOR) DISK SCHEDULING ---\n");
    printf("Enter Total Disk Size (e.g. 200): ");
    scanf("%d", &disk_size);
    
    printf("Enter Number of Requests: ");
    scanf("%d", &n);
    
    printf("Enter Request Queue:\n");
    for(i = 0; i < n; i++) {
        scanf("%d", &req[i]);
    }
    
    printf("Enter Initial Head Position: ");
    scanf("%d", &head);

    // Sort request queue in ascending order
    for(i = 0; i < n - 1; i++) {
        for(j = i + 1; j < n; j++) {
            if(req[i] > req[j]) {
                temp = req[i];
                req[i] = req[j];
                req[j] = temp;
            }
        }
    }

    // Locate initial head position
    pos = 0;
    while(pos < n && req[pos] < head) {
        pos++;
    }

    printf("\nHead Movement Traversal:\n%d", head);

    // Service requests towards the high boundary
    for(i = pos; i < n; i++) {
        seek += abs(req[i] - head);
        head = req[i];
        printf(" -> %d", head);
    }
    
    // Move to end of disk boundary
    seek += abs((disk_size - 1) - head);
    head = disk_size - 1;
    printf(" -> %d", head);

    // Reverse direction and service remaining requests
    for(i = pos - 1; i >= 0; i--) {
        seek += abs(req[i] - head);
        head = req[i];
        printf(" -> %d", head);
    }

    printf("\n\nTotal Head Movement (Seek Time) = %d Cylinders", seek);
    printf("\nAverage Seek Time = %.2f Cylinders\n", (float)seek / n);

    return 0;
}
