Experiment 1 Searching

Implementation and Performance Analysis of Interpolation Search

Problem Statement
Given a sorted array of uniformly distributed integers, implement Interpolation Search to find the position of a target element. Compare its performance with Binary Search for different dataset sizes (1000, 5000, 10000, 50000, 100000 elements).
Aim
To implement the Interpolation Search algorithm in Python and analyze its time complexity by measuring execution time on sorted datasets of varying sizes.
Algorithm
  1. Start the program.
  2. Input Data: Read the sorted array arr[0..n-1] of uniformly distributed elements and the target search value target.
  3. Initialize Pointers: Set the search boundary index pointers: low = 0 and high = n - 1.
  4. Probing Loop: While low ≤ high and arr[low] ≤ target ≤ arr[high], perform the following:
    1. Boundary Check: If low == high, check if arr[low] == target; if true, return low, otherwise return -1.
    2. Position Estimation: Estimate probe position using linear interpolation:
      pos = low + ⌊((target - arr[low]) * (high - low)) / (arr[high] - arr[low])⌋.
    3. Evaluation: If arr[pos] == target, return pos (Target located).
    4. Subarray Reduction: If arr[pos] < target, narrow search to the upper partition by setting low = pos + 1.
    5. Else: Narrow search to the lower partition by setting high = pos - 1.
  5. Absence Handling: If the loop terminates without finding the target, return -1 (element not found in array).
  6. Stop the program.

import time
import random
import sys

def interpolation_search(arr, target):
    """
    Interpolation Search Algorithm (Understandable Step-by-Step Implementation)
    - Prerequisite: Array MUST be sorted; works best on uniformly distributed data.
    - Probe Formula: pos = low + ((target - arr[low]) * (high - low)) // (arr[high] - arr[low])
    """
    low, high = 0, len(arr) - 1
    comparisons = 0

    # Continue search only while target is bounded by current window
    while low <= high and arr[low] <= target <= arr[high]:
        comparisons += 1

        # Check edge case: single element interval
        if low == high:
            if arr[low] == target:
                return low, comparisons
            return -1, comparisons

        # --- STEP 1: Calculate estimated probe position ---
        # Instead of fixed midpoint, estimate index proportional to value difference
        pos = low + int(((target - arr[low]) * (high - low)) / (arr[high] - arr[low]))

        # --- STEP 2: Compare target with estimated element ---
        if arr[pos] == target:
            return pos, comparisons         # Element found at estimated probe!
        elif arr[pos] < target:
            low = pos + 1                   # Target is greater; search right sub-array
        else:
            high = pos - 1                  # Target is smaller; search left sub-array

    return -1, comparisons                 # Element not found

def binary_search(arr, target):
    """Standard Binary Search for empirical comparison"""
    low, high = 0, len(arr) - 1
    comparisons = 0
    while low <= high:
        comparisons += 1
        mid = (low + high) // 2
        if arr[mid] == target:
            return mid, comparisons
        elif arr[mid] < target:
            low = mid + 1
        else:
            high = mid - 1
    return -1, comparisons

Experiment 2 Pattern Matching

Comparative Analysis of Naive, Rabin-Karp, and KMP Algorithms for String Matching

Problem Statement
Given a text string T of length n and a pattern string P of length m, implement all three string matching algorithms and compare the number of character comparisons made. Use a text of 10000 characters and patterns of varying lengths (5, 10, 20, 50 characters).
Aim
To implement and compare three string matching algorithms — Naive, Rabin-Karp, and Knuth-Morris-Pratt (KMP) — and analyze their time complexity and performance.
Algorithm
Algorithm 1: Naive String Matching
  1. Start the procedure.
  2. Read the text string T of length n and pattern string P of length m.
  3. Slide the pattern over the text for each shift i from 0 to n - m:
    1. Compare characters T[i + j] and P[j] for j = 0, 1, ..., m - 1.
    2. If all m characters match (j == m), report a valid match at index i.
  4. Stop.
Algorithm 2: Knuth-Morris-Pratt (KMP) Algorithm
  1. Start the procedure.
  2. Preprocess LPS Array: Construct the Longest Prefix Suffix (lps[0..m-1]) array for pattern P in O(m) time.
  3. Initialize text pointer i = 0 and pattern pointer j = 0.
  4. While i < n:
    1. If T[i] == P[j], advance both pointers: i = i + 1, j = j + 1.
    2. If j == m, report a match at index (i - j) and shift pattern using j = lps[j - 1].
    3. Else if i < n and T[i] != P[j]:
      • If j != 0, shift pattern using j = lps[j - 1] without backtracking text index i.
      • Else, increment text index: i = i + 1.
  5. Stop.
Algorithm 3: Rabin-Karp String Matching Algorithm
  1. Start the procedure.
  2. Select radix base d = 256 and prime modulus q = 101.
  3. Compute hash values of the pattern (h_p) and the first window of text (h_t).
  4. For shift s from 0 to n - m:
    1. If h_p == h_t, perform full character-by-character validation to confirm match and eliminate spurious collisions.
    2. If s < n - m, compute rolling hash for the next window in O(1) time by removing the leading character, shifting, and adding the trailing character modulo q.
  5. Stop.

import time
import random
import string

# =====================================================================
# 1. NAIVE BRUTE-FORCE STRING MATCHING
# Slides pattern window 1 char at a time; compares chars until mismatch.
# =====================================================================
def naive_search(text, pattern):
    n, m = len(text), len(pattern)
    matches, comparisons = [], 0

    for i in range(n - m + 1):
        j = 0
        while j < m:
            comparisons += 1
            if text[i + j] != pattern[j]:
                break  # Mismatch: slide window by 1
            j += 1
        if j == m:
            matches.append(i)  # Full match found!
    return matches, comparisons

# =====================================================================
# 2. KNUTH-MORRIS-PRATT (KMP) ALGORITHM
# Avoids re-evaluating text chars by using Longest Prefix Suffix (LPS).
# =====================================================================
def compute_lps(pattern):
    """Computes LPS array: length of longest proper prefix that is also suffix"""
    m = len(pattern)
    lps = [0] * m
    length, i = 0, 1

    while i < m:
        if pattern[i] == pattern[length]:
            length += 1
            lps[i] = length
            i += 1
        elif length != 0:
            length = lps[length - 1]  # Fallback to previous longest prefix
        else:
            lps[i] = 0
            i += 1
    return lps

def kmp_search(text, pattern):
    n, m = len(text), len(pattern)
    lps = compute_lps(pattern)  # Preprocessing Step: O(m)
    matches, comparisons = [], 0
    i = j = 0  # i: text pointer, j: pattern pointer

    while i < n:
        comparisons += 1
        if pattern[j] == text[i]:
            i += 1
            j += 1
        if j == m:
            matches.append(i - j)      # Pattern detected at index i - j
            j = lps[j - 1]             # Jump pattern pointer based on LPS
        elif i < n and pattern[j] != text[i]:
            if j != 0:
                j = lps[j - 1]         # Don't increment i; shift pattern pointer
            else:
                i += 1                 # Move text pointer forward
    return matches, comparisons

# =====================================================================
# 3. RABIN-KARP ROLLING HASH ALGORITHM
# Hashes the pattern and sliding windows; checks chars only on hash match.
# =====================================================================
def rabin_karp(text, pattern, q=101):
    n, m = len(text), len(pattern)
    d = 256  # Size of alphabet (ASCII)
    h = pow(d, m - 1, q)  # Multiplier factor d^(m-1) % q
    p_hash = t_hash = 0
    matches, comparisons = [], 0

    # Step 1: Calculate initial hash of pattern and first text window
    for i in range(m):
        p_hash = (d * p_hash + ord(pattern[i])) % q
        t_hash = (d * t_hash + ord(text[i])) % q

    # Step 2: Slide window over text
    for s in range(n - m + 1):
        # Step 2.1: Check if hashes match (candidate match)
        if p_hash == t_hash:
            for k in range(m):
                comparisons += 1
                if text[s + k] != pattern[k]:
                    break
            else:
                matches.append(s)  # Genuine match confirmed!

        # Step 2.2: Compute rolling hash for next window in O(1)
        if s < n - m:
            t_hash = (d * (t_hash - ord(text[s]) * h) + ord(text[s + m])) % q
            if t_hash < 0:
                t_hash += q
    return matches, comparisons

Experiment 3 Greedy / Graphs

Implementation of Kruskal's and Prim's Algorithms for Minimum Spanning Tree

Problem Statement
Given a weighted undirected graph with 7 vertices (0–6) and 9 edges, find the MST using both Kruskal's and Prim's algorithms. Verify that both produce the same total minimum weight and analyze their time complexity.
Aim
To implement Kruskal's and Prim's algorithms in Python to find the Minimum Spanning Tree (MST) of a weighted undirected graph and compare their performance.
Algorithm
Algorithm 1: Kruskal's MST (Edge-Centric Greedy Approach)
  1. Start the procedure.
  2. Input Graph: Read the connected, weighted, undirected graph G(V, E) with V vertices and E edges.
  3. Sort Edges: Sort all E edges in non-decreasing order of their weights: w(e_1) ≤ w(e_2) ≤ ... ≤ w(e_E).
  4. Initialize Disjoint Sets: For each vertex v ∈ V, initialize a distinct disjoint set using MAKE_SET(v).
  5. Initialize MST: Set the spanning tree edge collection T = ∅ and total cost total_cost = 0.
  6. Greedy Edge Selection: For each edge (u, v) with weight w in sorted order:
    1. Determine component sets: root_u = FIND_SET(u) and root_v = FIND_SET(v).
    2. If root_u != root_v (endpoints belong to different components, so no cycle is formed):
      • Add edge to MST: T = T ∪ {(u, v)}.
      • Accumulate weight: total_cost = total_cost + w.
      • Merge components: UNION(root_u, root_v).
    3. If |T| == V - 1, break early as the MST is complete.
  7. Output: Display all edges in MST T and the minimum total spanning weight.
  8. Stop.
Algorithm 2: Prim's MST (Vertex-Centric Greedy Approach)
  1. Start the procedure.
  2. Initialization: For every vertex v ∈ V, set key[v] = ∞, parent[v] = NIL, and inMST[v] = FALSE.
  3. Select an arbitrary starting root vertex s and set key[s] = 0.
  4. Insert all vertices into a Min-Priority Queue Q keyed by their key values.
  5. Growing the MST: While Q is not empty:
    1. Extract vertex with minimum key: u = EXTRACT_MIN(Q).
    2. Mark u as included in the spanning tree: inMST[u] = TRUE.
    3. For each adjacent neighbor v of u with edge weight w(u, v):
      • If inMST[v] == FALSE and w(u, v) < key[v]:
        • Update parent: parent[v] = u.
        • Update tentative key: key[v] = w(u, v).
        • Decrease key in priority queue: DECREASE_KEY(Q, v, w(u, v)).
  6. Output: Construct and print MST edges (parent[v], v) for all v != s and calculate the total weight.
  7. Stop.

import heapq

# =====================================================================
# 1. UNION-FIND (DISJOINT SET UNION) DATA STRUCTURE FOR KRUSKAL
# Uses Path Compression + Union by Rank for near-constant O(alpha(V)) time.
# =====================================================================
class UnionFind:
    def __init__(self, n):
        self.parent = list(range(n))  # Each node is initially its own parent
        self.rank = [0] * n           # Depth estimation for balancing trees

    def find(self, x):
        """Find root representative with Path Compression"""
        if self.parent[x] != x:
            self.parent[x] = self.find(self.parent[x])  # Flattens tree
        return self.parent[x]

    def union(self, x, y):
        """Union two sets by rank. Returns False if already in same set (cycle)."""
        rx, ry = self.find(x), self.find(y)
        if rx == ry:
            return False  # Cycle detected! Do not add this edge.

        # Attach smaller rank tree under root of higher rank tree
        if self.rank[rx] < self.rank[ry]:
            rx, ry = ry, rx
        self.parent[ry] = rx
        if self.rank[rx] == self.rank[ry]:
            self.rank[rx] += 1
        return True

# =====================================================================
# 2. KRUSKAL'S ALGORITHM
# Sorts all edges globally, then greedily selects lightest non-cycle edges.
# =====================================================================
def kruskal(n, edges):
    """edges: list of tuples (weight, u, v)"""
    edges.sort()  # Step 1: Sort all edges globally in O(E log E)
    uf = UnionFind(n)
    mst = []
    cost = 0

    # Step 2: Iterate through sorted edges
    for w, u, v in edges:
        if uf.union(u, v):          # If u and v belong to different components
            mst.append((u, v, w))   # Add edge to MST
            cost += w
        if len(mst) == n - 1:       # An MST always has exactly V - 1 edges
            break
    return mst, cost

# =====================================================================
# 3. PRIM'S ALGORITHM
# Starts from an arbitrary vertex; grows tree greedily using Min-Heap.
# =====================================================================
def prim(n, adj, start=0):
    """adj: adjacency list dictionary {u: [(v, weight), ...]}"""
    INF = float('inf')
    key = [INF] * n          # Minimum weight to connect vertex v to current tree
    parent = [-1] * n        # Parent pointer in MST
    inMST = [False] * n      # Track visited vertices in the growing tree
    key[start] = 0
    pq = [(0, start)]        # Min-heap priority queue stores (key, vertex)
    mst = []
    cost = 0

    while pq:
        # Step 1: Extract vertex with minimum key
        w, u = heapq.heappop(pq)
        if inMST[u]:
            continue
        inMST[u] = True

        if parent[u] != -1:
            mst.append((parent[u], u, w))
            cost += w

        # Step 2: Relax neighboring cut edges
        for v, wt in adj.get(u, []):
            if not inMST[v] and wt < key[v]:
                key[v] = wt
                parent[v] = u
                heapq.heappush(pq, (wt, v))

    return mst, cost

To implement Dijkstra's algorithm in Python to find the shortest path from a single source vertex to all other vertices in a weighted graph.
Algorithm

  2. Input Graph: Read weighted graph G(V, E) with non-negative edge weights w(u, v) ≥ 0 and a designated source vertex.
  3. Initialize Single-Source Distances:
    1. For all vertices v ∈ V, initialize distance dist[v] = ∞ and predecessor prev[v] = NIL.
    2. Set source distance to zero: dist[source] = 0.
    3. Initialize an empty visited set: visited = ∅.

  5. Greedy Settlement & Relaxation: While Q is not empty:
    1. Extract the vertex with minimum tentative distance: (d, u) = EXTRACT_MIN(Q).
    2. If u ∈ visited, skip this entry (stale queue entry).
    3. Mark vertex as settled: visited = visited ∪ {u}.
    4. For each neighbor v of u connected by edge weight w:
      • Relaxation Step: Check if dist[u] + w < dist[v].
      • If true, update optimal path distance: dist[v] = dist[u] + w.
      • Record optimal predecessor: prev[v] = u.
      • Insert updated tuple (dist[v], v) into priority queue Q.
  6. Path Reconstruction: For any destination vertex target, trace back through prev[] array from target to source to obtain the exact shortest path sequence.
  7. Output: Display the shortest distance from source to all other vertices and print the path trajectories.
  8. Stop.

import heapq

def dijkstra(graph, source):
    """
    Dijkstra's Single-Source Shortest Path using Binary Min-Heap
    - Requires: Non-negative edge weights (w >= 0).
    - graph: Adjacency list dictionary {u: [(v, weight), ...]}
    """
    n = len(graph)
    dist = [float('inf')] * n   # Shortest distances from source
    prev = [None] * n           # Parent pointers for path reconstruction
    dist[source] = 0

    # Min-Heap stores tuples of (tentative_distance, vertex)
    pq = [(0, source)]
    visited = set()

    while pq:
        # --- STEP 1: Extract settled vertex with lowest distance ---
        d, u = heapq.heappop(pq)
        if u in visited:
            continue
        visited.add(u)

        # --- STEP 2: Relax each outgoing adjacent edge (u -> v) ---
        for v, w in graph[u]:
            # Edge relaxation condition
            if dist[u] + w < dist[v]:
                dist[v] = dist[u] + w   # Shorter route discovered!
                prev[v] = u             # Record u as predecessor of v
                heapq.heappush(pq, (dist[v], v))

    return dist, prev

def reconstruct_path(prev, source, target):
    """Backtracks through parent array prev to reassemble the exact route"""
    path = []
    node = target
    while node is not None:
        path.append(node)
        node = prev[node]
    path.reverse()  # Reverse to get order: source -> ... -> target
    if path and path[0] == source:
        return path
    return []

To Find Min-Max Value by Applying Divide and Conquer Technique

Problem Statement

Aim
To implement the Divide and Conquer approach to simultaneously find the minimum and maximum elements in an array and compare it with the naive linear approach in terms of number of comparisons.
Algorithm
  1. Start the algorithm.
  2. Input Array: Read the input array arr[0..n-1] containing n numerical elements.
  3. Define Recursive Function MIN_MAX(arr, low, high):
    1. Base Case 1 (Single Element): If low == high, return (arr[low], arr[low]) as both minimum and maximum (0 comparisons).
    2. Base Case 2 (Two Elements): If high == low + 1:
      • If arr[low] < arr[high], return (arr[low], arr[high]).
      • Else, return (arr[high], arr[low]) (1 comparison).
    3. Divide Step: Find midpoint: mid = ⌊(low + high) / 2⌋.
    4. Conquer Step: Recursively compute extrema for both halves:
      • Left half: (min1, max1) = MIN_MAX(arr, low, mid)
      • Right half: (min2, max2) = MIN_MAX(arr, mid + 1, high)
    5. Combine Step: Compare the recursive sub-solutions with exactly 2 comparisons:
      • Overall Minimum: overall_min = min(min1, min2)
      • Overall Maximum: overall_max = max(max1, max2)
    6. Return (overall_min, overall_max).
  4. Execute Main Call: Call MIN_MAX(arr, 0, n - 1) to evaluate the array in 3n/2 - 2 comparisons.
  5. Output: Print the determined global minimum and maximum values along with comparison counts.
  6. Stop.

import random

comparison_count = 0  # Global counter to track elemental comparisons

def min_max_dc(arr, low, high):
    """
    Finds (min, max) using Divide and Conquer.
    Recurrence: T(n) = 2T(n/2) + 2 comparisons
    Total comparisons: 3n/2 - 2 (for n power of 2)
    """
    global comparison_count
    
    # --- Step 1: Base Case: Single element array ---
    if low == high:
        return arr[low], arr[low]
        
    # --- Step 2: Base Case: Two element subarray (1 comparison) ---
    if high == low + 1:
        comparison_count += 1
        if arr[low] < arr[high]:
            return arr[low], arr[high]
        return arr[high], arr[low]
        
    # --- Step 3: Divide into two halves ---
    mid = (low + high) // 2
    lmin, lmax = min_max_dc(arr, low, mid)
    rmin, rmax = min_max_dc(arr, mid + 1, high)
    
    # --- Step 4: Combine subproblem results (2 comparisons) ---
    comparison_count += 1
    overall_min = lmin if lmin < rmin else rmin
    
    comparison_count += 1
    overall_max = lmax if lmax > rmax else rmax
    
    return overall_min, overall_max

        comps += 1
        if x < mn: 
            mn = x
        comps += 1
        if x > mx: 
            mx = x

def matrix_chain_order(dims):
    """
    Computes optimal matrix chain multiplication order using Dynamic Programming.
    dims: list of dimensions where matrix A_i has dimension dims[i-1] x dims[i]
    Time Complexity:  O(n^3)
    Space Complexity: O(n^2) for memoization tables
    """
    n = len(dims) - 1
    
    # Step 1: Initialize DP cost table m and split table s
    # m[i][j] stores minimum scalar multiplications needed for A_i..A_j
    # s[i][j] stores the optimal split index k that achieves m[i][j]
    m = [[0] * (n + 1) for _ in range(n + 1)]
    s = [[0] * (n + 1) for _ in range(n + 1)]
    
    # Step 2: Iterate through subchain lengths l from 2 to n
    for l in range(2, n + 1):
        for i in range(1, n - l + 2):
            j = i + l - 1
            m[i][j] = float('inf')
            
            # Step 3: Evaluate all potential split points k
            for k in range(i, j):
                # Cost = left subchain cost + right subchain cost + cost of multiplying results
                cost = m[i][k] + m[k + 1][j] + dims[i - 1] * dims[k] * dims[j]
                if cost < m[i][j]:
                    m[i][j] = cost
                    s[i][j] = k  # Store optimal split
                    
    return m, s

def print_optimal_parens(s, i, j):
    """Recursively reconstructs the parenthesized multiplication sequence."""
    if i == j:
        return f'A{i}'
    k = s[i][j]
    left = print_optimal_parens(s, i, k)
    right = print_optimal_parens(s, k + 1, j)
    return f'({left} x {right})'

      • Recurse to next row: call SOLVE_N_QUEENS(board, row + 1).

def is_safe(board, row, col):
    """
    Checks if a queen can be safely placed at (row, col).
    Verifies that no previous queen shares the same column or diagonal.
    """
    for prev_row in range(row):
        placed = board[prev_row]
        # Column conflict check
        if placed == col:
            return False
        # Diagonal conflict check (|row1 - row2| == |col1 - col2|)
        if abs(prev_row - row) == abs(placed - col):
            return False
    return True

def solve_n_queens(n):
    """
    Solves N-Queens problem using Backtracking (Depth-First State Space Search).
    Returns list of all valid configurations and total backtracks executed.
    """
    board = [-1] * n  # board[r] stores column index for queen in row r
    solutions = []
    backtrack_count = [0]

    def backtrack(row):
        # Step 1: Base case - All n rows successfully placed
        if row == n:
            solutions.append(board[:])
            return
            
        # Step 2: Try placing queen in each column of current row
        for col in range(n):
            if is_safe(board, row, col):
                board[row] = col           # Choose
                backtrack(row + 1)         # Explore
                board[row] = -1            # Un-choose (Backtrack)
                
        # Count dead-end backtrack events
        backtrack_count[0] += 1

    backtrack(0)
    return solutions, backtrack_count[0]

Experiment 8 Branch and Bound

Travelling Salesman Problem using Branch and Bound for Finding Optimal Path

Problem Statement
Given a 5-city TSP with a known cost matrix, find the minimum cost Hamiltonian cycle using Branch and Bound with a lower-bound estimation based on reduced cost matrices. Display the optimal tour and its total cost.
Aim
To implement the Branch and Bound technique to solve the Travelling Salesman Problem (TSP) and find the optimal tour that visits all cities exactly once and returns to the starting city with minimum cost.
Algorithm
  1. Start the procedure.
  2. Input Cost Matrix: Read the n × n cost matrix C for n cities, setting self-loops C[i][i] = ∞.
  3. Define Matrix Reduction Procedure REDUCE(matrix):
    1. Row Reduction: For each row i, find minimum non-∞ value r_min. If r_min > 0, subtract r_min from every element in row i and add r_min to cumulative lower bound LB.
    2. Column Reduction: For each column j, find minimum non-∞ value c_min. If c_min > 0, subtract c_min from every element in column j and add c_min to cumulative lower bound LB.
    3. Return the reduced matrix and the combined reduction cost LB.
  4. Initialize State Space Search:
    1. Reduce original matrix C to obtain initial lower bound: (M_0, LB_0) = REDUCE(C).
    2. Create root state node: city = 0, path = [0], cost = LB_0, level = 1.
    3. Set global minimum tour cost min_cost = ∞ and push root node into Min-Priority Queue Q.
  5. Branch and Bound Traversal: While Q is not empty:
    1. Extract node with smallest estimated lower bound: curr = EXTRACT_MIN(Q).
    2. Pruning Check: If curr.cost ≥ min_cost, prune this subtree immediately.
    3. Leaf Check: If curr.level == n (all n cities visited):
      • Complete cycle by returning to city 0: total_cost = curr.cost + curr.matrix[curr.city][0].
      • If total_cost < min_cost, update min_cost = total_cost and record optimal tour best_path = curr.path + [0].
    4. Branching: For each unvisited city v:
      • Copy curr.matrix into child matrix M_child.
      • Set row curr.city and column v to ∞ to prevent re-visitation.
      • Set M_child[v][0] = ∞ to prevent premature sub-tour closure.
      • Reduce child matrix: (M_child, add_cost) = REDUCE(M_child).
      • Compute child lower bound: child_cost = curr.cost + curr.matrix[curr.city][v] + add_cost.
      • If child_cost < min_cost, insert child state into priority queue Q.
  6. Output: Display the optimal tour trajectory sequence and the minimum travelling cost.
  7. Stop.

def reduce_matrix(mat):
    """
    Computes lower bound reduction for TSP cost matrix.
    Subtracts row minimums and column minimums to produce reduced cost matrix.
    Sum of reductions provides rigorous lower bound on any tour in this branch.
    """
    m = [row[:] for row in mat]
    n = len(m)
    cost = 0
    
    # Step 1: Row reduction
    for i in range(n):
        row_min = min(m[i])
        if row_min and row_min != INF:
            cost += row_min
            m[i] = [x - row_min if x != INF else INF for x in m[i]]
            
    # Step 2: Column reduction
    for j in range(n):
        col_min = min(m[i][j] for i in range(n))
        if col_min and col_min != INF:
            cost += col_min
            for i in range(n):
                if m[i][j] != INF:
                    m[i][j] -= col_min
                    
    return m, cost

def first_fit(items, capacity=1.0):
    """
    First Fit (FF) Approximation:
    Places each item into the first bin with sufficient remaining space.
    Time Complexity: O(n^2) naive, O(n log n) with balanced search tree.
    """
    bins = []          # Tracks remaining capacity in each bin
    bin_contents = []  # Stores item lists for each bin
    
    for item in items:
        placed = False
        # Search for first bin with enough headroom
        for i, space in enumerate(bins):
            if space >= item:
                bins[i] -= item
                bin_contents[i].append(item)
                placed = True
                break
        # No existing bin has room: open new bin
        if not placed:
            bins.append(capacity - item)
            bin_contents.append([item])
            
    return bin_contents

def first_fit_decreasing(items, capacity=1.0):
    """
    First Fit Decreasing (FFD) Approximation:
    Pre-sorts items in non-increasing order, then applies First Fit.
    Guaranteed: Bins <= (11/9)*OPT + 6/9
    """
    return first_fit(sorted(items, reverse=True), capacity)

def best_fit_decreasing(items, capacity=1.0):
    """
    Best Fit Decreasing (BFD) Approximation:
    Sorts descending, then places each item into the tightest fitting bin
    (minimizing leftover space in that bin).
    """
    sorted_items = sorted(items, reverse=True)
    bins = []
    bin_contents = []
    
    for item in sorted_items:
        best_idx = -1
        best_space = float('inf')
        # Find bin that leaves minimum leftover space
        for i, space in enumerate(bins):
            if space >= item and (space - item) < best_space:
                best_space = space - item
                best_idx = i
        if best_idx >= 0:
            bins[best_idx] -= item
            bin_contents[best_idx].append(item)
        else:
            bins.append(capacity - item)
            bin_contents.append([item])
            
    return bin_contents

import random
import time
import sys

sys.setrecursionlimit(20000)
comparisons = 0  # Global counter to track elemental comparisons

def partition(arr, low, high):
    """
    Standard Lomuto partitioning scheme:
    Places pivot arr[high] at its correct sorted position.
    Elements <= pivot are moved to left; elements > pivot moved to right.
    """
    global comparisons
    pivot = arr[high]
    i = low - 1
    for j in range(low, high):
        comparisons += 1
        if arr[j] <= pivot:
            i += 1
            arr[i], arr[j] = arr[j], arr[i]
    arr[i + 1], arr[high] = arr[high], arr[i + 1]
    return i + 1

def deterministic_quicksort(arr, low, high):
    """Deterministic Quick Sort: Always uses arr[high] as pivot."""
    if low < high:
        pi = partition(arr, low, high)
        deterministic_quicksort(arr, low, pi - 1)
        deterministic_quicksort(arr, pi + 1, high)

def randomized_quicksort(arr, low, high):
    """
    Randomized Quick Sort: Selects a pivot uniformly at random from arr[low..high],
    swapping it to high before calling partition.
    Guarantees expected O(n log n) time on all input distributions.
    """
    if low < high:
        # Step 1: Select uniform random pivot index and swap to end
        rand_idx = random.randint(low, high)
        arr[rand_idx], arr[high] = arr[high], arr[rand_idx]
        
        # Step 2: Standard partition and recursive conquer
        pi = partition(arr, low, high)
        randomized_quicksort(arr, low, pi - 1)
        randomized_quicksort(arr, pi + 1, high)

def run_test(name, sort_fn, arr):
    """Helper function to execute sort and return comparison count and duration."""
    global comparisons
    a = arr[:]
    comparisons = 0
    start = time.perf_counter()
    sort_fn(a, 0, len(a) - 1)
    elapsed = (time.perf_counter() - start) * 1000
    return comparisons, elapsed

Randomized Quick Sort avoids adversarial inputs by selecting the pivot randomly, guaranteeing expected O(n log n) performance. This is why practical implementations (Python's Timsort, C++ introsort) use randomization or median-of-three pivot selection. Randomized algorithms trade determinism for robustness against worst-case inputs.
